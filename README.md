# Hi, I'm okeya24

Building local-first AI applications — things that run on your own machine, not someone else's cloud.

## What I'm working on

**[LifeOS](https://github.com/okeya24/lifeos-local-showcase)** — a local-first personal universe app.
React + Three.js frontend, Node backend, model calls routed through a provider abstraction layer so the
same app can run against Ollama (local) or a cloud API without touching business code.
Voice conversation, note-taking, packaged as a developer preview.

## What I care about

- **Local-first**: data stays on the machine, inference can too.
- **Cost awareness**: knowing what a request actually costs, not just "it works".
- **Understanding the layer beneath the tool**: I use Dify and Codex, and I also write the retrieval
  and the agent loop by hand — otherwise the tool is doing the thinking for me.

## Stack

`TypeScript` · `React` · `Node.js` · `FastAPI` · `Ollama` · `Docker` · `Dify`

Currently learning: RAG evaluation, agent tool-calling, and how to measure whether an AI feature
is actually good instead of just demo-able.
